# project-real
Project R.E.A.L. (Renewable Energy Asset Locator) is a cloud-native geospatial machine learning pipeline designed to accelerate utility-scale solar PV site selection across the Riyadh Province. By replacing memory-intensive raster grids with a vectorized point-sampling architecture, R.E.A.L. cuts memory overhead by 90% and predicts land suitability in under two seconds. The engine benchmarks ensemble architectures (Random Forest and XGBoost) against multi-modal environmental data—including ERA5-Land solar irradiance, NASA SRTM elevation, OpenStreetMap transmission networks, and WDPA conservation boundaries—to deliver rapid, environmentally compliant decision support aligned with Saudi Vision 2030 and SDG 15.
